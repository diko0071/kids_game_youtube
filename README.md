# МультиИгра

Детский YouTube-каталог с короткими развивающими играми между мультфильмами.

Production: [kids-game-youtube.vercel.app](https://kids-game-youtube.vercel.app/)

## Поведение продукта

1. На главном экране ребёнок выбирает одну из пяти тем: истории, обучение, техника, песни или приключения.
2. Внутри темы показывается небольшой каталог мультфильмов с обложками, языком и названием канала.
3. Экран просмотра сохраняет стандартные YouTube-кнопки и даёт два явных выхода: назад к мультфильмам темы или ко всем темам.
4. Таймер считает только секунды, когда YouTube действительно воспроизводит видео. Пауза, загрузка, настройки и игра не расходуют время просмотра.
5. Через выбранный интервал видео ставится на паузу и появляется одна из пяти игр. После правильного ответа мультфильм продолжается автоматически.
6. Взрослый может выбрать интервал 1, 3, 5, 10 или 15 минут, включить или выключить голос, отключить отдельные игры и проверить любую игру вручную. Настройки сохраняются в браузере.
7. Старые прямые ссылки вида `?video=...` продолжают открываться. Ссылка `?video=OBjkNW11ujM` сохранена, но воспроизводит рабочий официальный ролик «Лунтика», потому что исходный ролик запрещён владельцем для встраивания.

## Пять игр

- Буквы: услышать задание и найти такую же русскую букву.
- Счёт: сосчитать от двух до шести фигур и выбрать число.
- Цвета: найти названный цвет.
- Картинка и слово: сопоставить изображение с русским словом.
- Слоги: собрать знакомое слово из двух слогов.

Все основные русские фразы записаны локально и работают без поддержки системного синтеза речи. Если локальная запись недоступна, приложение пробует системный голос.

## Локальная разработка

```bash
npm ci
npm run dev
```

Проверки перед публикацией:

```bash
npm run typecheck
npm test
npm run build
npm audit --omit=dev
```

## Публикация

Vercel связан с GitHub-репозиторием. Pull request получает preview deployment, а merge в `main` запускает production deployment на основном URL.

## Технологии

- Next.js 16 и React 19
- YouTube IFrame Player API
- Vitest
- Адаптивная вёрстка без внешней UI-библиотеки
