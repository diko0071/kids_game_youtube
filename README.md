# МультиИгра

Детский YouTube-каталог с короткими развивающими играми между мультфильмами.

Production: [kids-game-youtube.vercel.app](https://kids-game-youtube.vercel.app/)

## Поведение продукта

1. Приложение всегда открывается на одном экране: большой YouTube-плеер и каталог рядом с ним.
2. Поиск фильтрует безопасный семейный каталог по названию, каналу, типу и русским словам-подсказкам.
3. Кнопка «Тип» открывает отдельный фильтр: все видео, истории, обучение, техника, песни и приключения. Выбор типа не прерывает текущий мультфильм.
4. На компьютере каталог находится справа от плеера, на телефоне — под ним. Прокручивается только список роликов.
5. Единственный служебный элемент постоянного интерфейса — кнопка «Для взрослых».
6. Скрытый таймер считает только секунды, когда YouTube действительно воспроизводит видео. Пауза, загрузка, настройки и игра не расходуют время просмотра.
7. Через выбранный интервал видео ставится на паузу и появляется одна из пяти игр. После правильного ответа мультфильм продолжается автоматически.
8. Взрослый может выбрать интервал 1, 3, 5, 10 или 15 минут, включить или выключить голос, отключить отдельные игры и проверить любую игру вручную. Настройки сохраняются в браузере.
9. Прямые ссылки вида `?video=...` и `?theme=...&video=...` открывают только одобренные ролики; параметр `theme` сразу выбирает нужный тип каталога.
10. В настройках для взрослых есть поиск на официальном YouTube. Он открывается отдельно и не расширяет закрытый детский allowlist автоматически.

## Пять игр

- Буквы: услышать задание и найти такую же русскую букву.
- Счёт: сосчитать от двух до шести фигур и выбрать число.
- Цвета: найти названный цвет.
- Картинка и слово: сопоставить изображение с русским словом.
- Слоги: собрать знакомое слово из двух слогов.

Все основные русские фразы записаны локально и работают без поддержки системного синтеза речи. Если локальная запись недоступна, приложение пробует системный голос.

## Локальная разработка

```bash
npm ci
npm run dev
```

Проверки перед публикацией:

```bash
npm run typecheck
npm test
npm run build
npm audit --omit=dev
```

## Публикация

Vercel связан с GitHub-репозиторием. Pull request получает preview deployment, а merge в `main` запускает production deployment на основном URL.

## Технологии

- Next.js 16 и React 19
- YouTube IFrame Player API
- Vitest
- Адаптивная вёрстка без внешней UI-библиотеки
